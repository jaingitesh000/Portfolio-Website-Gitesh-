# Gitesh Jain Portfolio

The site uses plain HTML, CSS, and JavaScript with Tailwind compiled locally.

## Structure

- `index.html` — homepage only
- `projects/quest-plus.html` — Quest+ case study
- `projects/teacher-tools.html` — Teach Portal and Mobile App case study
- `projects/group-masterclass.html` — Group Masterclass case study
- `css/custom.css` — authored component and interaction styles
- `css/styles.css` — generated Tailwind output
- `js/app.js` — shared navigation, project rendering, animation, and interaction logic
- `src/input.css` — Tailwind source entry
- `assets/` — images, SVGs, and Lottie data

## Commands

```bash
npm run build
npm run watch
```

Edit `css/custom.css` for custom styles. Do not edit `css/styles.css` directly because the Tailwind build regenerates it.
